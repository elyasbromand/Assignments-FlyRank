# FlyRank AI Internship Assignments

## About

This repository contains the assignments I completed during my Backend AI Engineering internship at FlyRank AI.

Each folder represents a separate assignment focused on a different backend or AI engineering concept.

Each folder is an independent project.

## Running an Assignment

1. Open the assignment folder.
2. Read that folder's README.
3. Follow the respective guideline.
4. Run the project.
